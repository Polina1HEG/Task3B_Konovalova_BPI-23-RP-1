# Практическое задание 3Б: Справочник пользователей (REST API)

## Описание
Интерактивное веб-приложение, которое загружает список пользователей с публичного API (`jsonplaceholder.typicode.com`), позволяет фильтровать их по имени и просматривать первые три публикации каждого пользователя.

## Как запустить
1. Скачайте все файлы проекта (`index.html`, `style.css`, `app.js`).
2. Откройте файл `index.html` в любом браузере.

## Результаты проверки (Чек-лист)
- **Загрузка пользователей:** При нажатии на кнопку «Загрузить пользователей» появляются 10 карточек с именем, email и городом.
- **Поиск:** При вводе «Leanne» в поле поиска список фильтруется в реальном времени без сетевых запросов. При вводе несуществующего имени отображается сообщение «Пользователи не найдены». Поиск нечувствителен к регистру.
- **Публикации:** Кнопка «Показать публикации» отправляет запрос `posts?userId=ID` и выводит заголовки и текст первых трёх публикаций в отдельную область справа.
- **Обработка ошибок:** При запросе отображается статус «Загрузка...», кнопка «Загрузить» блокируется до завершения запроса (обработка через `try/catch/finally`). При возникновении ошибки (например, 404) выводится понятное сообщение, и приложение остается работоспособным для повторных попыток.
